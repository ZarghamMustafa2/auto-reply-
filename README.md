# MetaHub — Messenger Broadcast & Auto-Reply Hub 🚀

MetaHub is a premium, client-side marketing automation platform for Facebook Pages. It enables businesses to securely synchronize Page-Scoped User IDs (PSIDs), configure smart anti-spam pacing delays, and dispatch high-converting bulk inbox broadcasts with a single click. It also features a fully customizable bilingual (English/Urdu) automated keyword response console.

## ✨ Features

- **Modern Glassmorphic UI**: Sleek, fully responsive marketing landing page and interactive simulated developer dashboard.
- **Bulk Broadcaster**: Send personalized messages using `[name]` placeholder tags with safety pacing controls.
- **Bilingual Auto-Replies**: Support for instantaneous toggling between English and Urdu keyword triggers and translations.
- **Meta Graph API Settings**: Simple integration fields with sandbox simulation mode pre-activated.
- **Client-Side Security**: All tokens, credentials, and configuration records are saved locally inside your browser's private storage sandbox (`localStorage`).

## 📁 File Structure

- `index.html` - Premium dark-mode glassmorphic landing page.
- `landing.css` - Custom styling tokens, animations, and typography for the landing page.
- `landing.js` - Interactive billing switcher and soft scrolling logic.
- `dashboard.html` - Feature-rich bilingual simulation dashboard.
- `style.css` - Theme variables, dashboard layout, and terminal simulation styling.
- `app.js` - Dynamic translation system, broadcaster queues, and auto-reply rule engine.

## 🚀 How to Run Locally

1. Clone this repository or download the source files.
2. Open `index.html` in any web browser to explore the landing page.
3. Click "Sign In" or "Try it Free" to load the interactive admin dashboard (`dashboard.html`).
